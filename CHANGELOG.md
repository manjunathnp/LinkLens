# Changelog

All notable changes to LinkLens are documented in this file.

## [1.3.1] - 2026-09-22

### Added

- Evidence-based separation of verified outcomes, confirmed failures, access and response details, and interactive application actions.
- Result-reason and viewport filters across the application and exported reports.
- Tech Book Store product demo with real desktop, mobile, light, dark, coverage, evidence, and export captures.
- Standalone interactive product walkthrough, unchanged captured result, provenance, and self-contained report.
- Reciprocal LENS Trio references for A11yLens, LinkLens, and ImageLens.

### Improved

- Per-destination summaries and result explanations throughout the overview, inventory, evidence, and exports.
- Positive, precise coverage language for supported exploration and useful follow-up journeys.

## [1.3.0] - 2026-09-21

### Added

- Approved LinkLens identity and shared LENS visual tokens.
- System, light, and dark themes with responsive desktop and mobile layouts.
- Fresh-audit state, logo-to-home navigation, and viewport-specific filters.

## [1.2.0] - 2026-09-20

### Added

- Headless signed-in destination verification with transferred cookie and browser-storage context.
- Entire-website discovery from the selected entry point and origin home page.
- Individual and full scan-history deletion.
- Desktop Web App and Mobile Web App viewport selection.
