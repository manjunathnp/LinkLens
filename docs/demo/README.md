# LinkLens — Tech Book Store Demo

Open `index.html` in a browser to explore the captured LinkLens workflow and evidence. Keep the screenshots, assets, stylesheet and script alongside it.

The screenshots and exported report come from a fresh UI-driven scan of `http://127.0.0.1:3000/techbookstore-shop.html`, the Tech Book Store public storefront. Scope: current page, desktop and mobile viewports. The run recorded 122 link observations across 40 unique destinations: 110 verified working, zero confirmed broken and 12 sign-in-required destination checks. The verified destination success rate was 100%.

See `capture-provenance.json` for scan metadata, `capture-result.json` for the unchanged scan result, and `tech-book-store-report.html` for the self-contained export.
